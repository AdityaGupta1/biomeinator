# Formation texture sources

The following unmodified tiles were selected from the user's local **16px Seamless
MC Texture Hyperpack**, compiled by Reactorcore. The user is verifying individual
tile provenance; selection is not a claim of verified original authorship.

| Local file | Original filename under `tiles/` | Selection |
|---|---|---|
| `gray_sandstone.png` | `stone (46).png` | T03 |
| `buff_sandstone.png` | `stone (3).png` | T05 |
| `dark_sandstone.png` | `stone1 (2).png` | T06 |

The Q01 and T07 textures are separately attributed in
[`yuushya/SOURCES.md`](yuushya/SOURCES.md) and stored in that folder under its license.
No textures were taken from mega-minecraft. None of these five selected source images
matched the exact pixels of the installed vanilla block textures checked for the
selection sheet; that comparison does not rule out modified derivatives.
